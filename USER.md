## Expected Routes

- Photo: use `capture_image`, then send the returned file path through Telegram.
- Disease prediction: use `daily-vineyard-briefing mode=run_board_prediction`
  with `repo_path=/root/.picoclaw/workspace/goidanich` and a field resolved
  from config.
- Current risk: use `daily-vineyard-briefing mode=get_current_risk`.
- Plot/report: use `daily-vineyard-briefing mode=generate_period_plot` with
  `board_only=true` so the board uses the pandas-free plot route.
- Standard disease report: use `daily-vineyard-briefing mode=standard_report`
  with `board_only=true` and normally `notify=false`; set `notify=true` only
  for explicit scheduled/unsolicited notification or "send this to Telegram"
  requests. Do not hand-compose a report from only
  `board_predict`. Send top-level `send_text` and attach top-level
  `send_photo_path` / `send_image_path` as a Telegram photo. If
  `must_attach_image=true`, do not send the board path as text. If
  `must_send_exactly=true`, do not replace it with a short summary or a combined
  multi-disease bullet list.
- If a tool name says `vineyard_guard`, it must be treated as the same full
  standard report route, not as a nominal-risk summary.
- If picoClaw rewrites a standard report, it must validate the rewritten text
  with `report-guard`; invalid reports must not be shown or sent.
- Missing/stale rows: use `vineyard-disease-risk mode=board_fill_gaps` only for
  the missing date window, then rerun the report with `days=31`. Do not expand
  normal farmer reports to 365 days.
- Missing model state: use the unified `vineyard-disease-risk
  mode=board_update_dashboard` refresh path for the same field/date window,
  then rerun the standard report. Only say a model layer is unavailable if this
  refresh path fails and include the failure JSON.
- Alerts: use `daily-vineyard-briefing mode=daily_briefing` with `board_only=true`;
  Telegram sends only the produced outbox artifact.

## Standard Vineyard Report

When the user asks for a disease report, the answer should be standardized:

1. risk today;
2. description of the general situation;
3. prediction depending on weather forecast/projection data;
4. fungal pressure in general, this week, and last week when available;
5. whether risk is high or low;
6. whether treatment is indicated, with field confirmation caveat;
7. real plot path generated by Goidanich code.

Do not fill these sections with generic vineyard talk. Use config plus
`daily-vineyard-briefing`, `vineyard-disease-risk`, and `farmer-report-compose`
outputs. If data is absent, run the regeneration skill route first.

Risk wording:

- below 50% is low risk and does not indicate treatment;
- 50-69.9% is moderate/watch risk;
- 70% and above is high risk.

15% is low risk. Do not describe it as high, critical, urgent, or a treatment
signal.
